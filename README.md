## ❌⭕ Tic Tac Toe Game (JavaScript)

---

### 🎯 Objective
To practice JavaScript game logic, DOM manipulation, and event handling by building an interactive browser-based game.

---

### ⚙️ Features
- Two-player gameplay (X vs O)
- Real-time turn switching
- Automatic win and draw detection
- Game reset functionality
- Clean and responsive UI

---

### 🛠 Tech Stack
- **Language:** JavaScript
- **Frontend:** HTML, CSS
- **Tools:** Git, GitHub

---
No backend required — runs directly in the browser.
---

### 🚀 How to Run Locally
```bash
git clone https://github.com/iysankhyan1902/Tic-Tac-Toe-game-Jscript.git
cd Tic-Tac-Toe-game-Jscript
open index.html


📂 Project Structure
Tic-Tac-Toe-game-Jscript/
├── index.html
├── style.css
├── app.js
```
